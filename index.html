Blender-style Extensions

Manage tools and editor add-ons

Bundled extensions run inside this editor. Native Blender Python add-ons cannot run in a browser. A custom .js/.mjs file must default-export an object like { id, name, version, description, activate(api) }. The activate function can call api.registerTool({ id, label, description, run(context) }) and return a cleanup function. Custom JavaScript runs with this page's permissions, so only install code you trust. Third-party extensions are session-only and must be re-selected after refreshing.
